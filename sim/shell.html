Cardputer Simulator

This is the same program that goes onto the device, drawing the same pixels with the same fonts. Click the screen and type on your own keyboard, or press the keys below.

Starting…

Try this

  • Press any letter on the home screen to start a sitting of cards.
  • A new card shows its answer. Read it and type it, for example eki for えき, then Enter.
  • A little later the same card comes back as a question.
  • Tab is the help key: first the romaji, then the answer.
  • Tab on the home screen opens the menu: single decks, the kana round, the keys, and settings with the four looks.

What it is not yet

  • Text only so far. Sound comes next.
  • The device has no clock. After a day with answers, the next start asks whether a new day has begun.
